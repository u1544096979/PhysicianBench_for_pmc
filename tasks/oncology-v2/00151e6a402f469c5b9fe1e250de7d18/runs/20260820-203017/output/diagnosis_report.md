## 疗效结论
**PR（部分缓解，Partial Response）**

## 判定依据

1. **目标病灶缩小≥30%（满足PR标准）** [14][22]：
   - 右上叶肿块最大径从基线 5.0 cm 缩小至 3.1 cm
   - 缩小幅度 = (5.0 - 3.1) / 5.0 × 100% = **38%**
   - 符合RECIST 1.1 PR标准（目标病灶最长径总和较基线缩小≥30%）

2. **淋巴结病灶缩小（非目标病灶改善）** [14][20][22]：
   - 右肺门及纵隔淋巴结从基线增大，经治疗后持续缩小，无增大证据

3. **无疾病进展证据** [22]：
   - 无新发病灶
   - 无远处转移（基线颅脑MRI、SPECT骨显像、腹部CT未见转移 [14]，治疗后未报告新发转移）

4. **肿瘤标志物下降佐证** [23]：
   - 2023-08-14 CEA、CYFRA21-1显著下降，与影像学缓解一致

5. **临床评估** [21][24]：
   - 2023-06-14 影像结论：对新辅助阿来替尼治疗有明显影像学缓解（RECIST 1.1评估）
   - 2023-08-14 疗效评估：达到手术切除条件，可手术

**结论**：该患者经新辅助阿来替尼靶向治疗5个月后，目标病灶缩小38%（≥30%），非目标病灶改善，无新发病灶及远处转移，按RECIST 1.1标准判定为 **PR（部分缓解）**。
