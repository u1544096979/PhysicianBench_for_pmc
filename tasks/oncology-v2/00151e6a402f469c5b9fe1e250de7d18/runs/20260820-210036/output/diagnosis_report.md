## 疗效结论
**PR（部分缓解，Partial Response）**

## 判定依据
1. **RECIST 1.1 目标病灶缩小幅度**：以基线右上叶肿块最长径 5.0 cm [14] 为参照，2023-08-14 影像最长径 3.1 cm [22]，缩小 = (5.0 − 3.1) / 5.0 ≈ **38% ≥ 30%**，满足 PR 标准；未达 CR（病灶未完全消失），亦非 SD（SD 要求缩小 <30%）或 PD（PD 需 ≥20% 且绝对值 ≥5 mm 进展）。
2. **既往一次评估（2023-06-14）[21]** 已明确"对新辅助阿来替尼治疗有明显影像学缓解（RECIST 1.1 评估）"，与本次影像持续缩小一致 [22]。
3. **淋巴结病灶**：基线右肺门及双侧纵隔淋巴结增大 [14]，至本次评估"受累淋巴结继续缩小" [22]，未出现新增或进展。
4. **肿瘤标志物**：2023-08-14 动态检测 CEA、CYFRA21-1 显著下降 [23]，与影像缓解相互印证。
5. **无新增病灶**：治疗期间未记录新发病灶或远处转移；无不良反应记录，治疗耐受良好。

> 备注：评估结论为 PR，而非 CR；临床同时记录"可手术（达到手术切除条件）" [24]，提示该 PR 为新辅助靶向治疗后的可手术缓解状态，但 RECIST 1.1 影像疗效分类仍为部分缓解（PR）。
