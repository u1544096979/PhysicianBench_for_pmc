## 疗效结论：PR（部分缓解）

## 判定依据

1. **主要靶病灶显著缩小**：2021-10-28 CT显示双肺弥漫性病灶较基线（2021-08-23）"明显退缩"、"明显减少"[48]，提示主要可评估病灶最大径之和较基线缩小≥30%，符合RECIST 1.1 PR标准。

2. **无新发病灶**：评估时影像未见新发病灶描述[48]，不满足PD标准。

3. **非完全缓解**：CEA仍为37.9 ng/mL（参考0-5）[44]，提示体内仍有残余肿瘤负荷，病灶未完全消失，不符合CR标准。

4. **肿瘤标志物支持客观缓解**：CYFRA21-1恢复正常（3.0 ng/mL）[45]，CA125显著下降（191→40.1）[47]，CEA下降51%[44]，与影像学改善一致，进一步支持PR判断。

5. **综合临床评估**：影像科医师评估结论为"部分缓解"[49]，与RECIST 1.1 PR判定一致。

**局限性说明**：本评估主要基于胸部CT对双肺弥漫性病灶的评估；脑转移灶（2021-09-07发现伴出血）[28][29]及骨转移灶[26]在评估时点未见复查影像数据，无法完整评估所有转移灶变化。但基于可评估的主要肺部病灶显著缩小且无新发病灶，整体疗效判定为PR是合理的。
